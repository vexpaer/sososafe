## sososafe v0.1.0

首个 Android 原生版本。下载 **sososafe.apk** 安装，支持 Android 8.0 及以上，以及 ARM64 / ARMv7 / x86_64。

- 普通、Shizuku、Root 统一扫描，权限与 AppOps 审计。
- APK / DEX / Manifest 分析，离线 SDK、域名与风险证据。
- 本地 VPN TCP / UDP 转发，DNS、连接元数据与 UID 流量记录。
- 确认后的权限限制、停用和卸载，操作历史与回滚。
- 中文 / English 首次选择与设置切换，轻边框圆角界面、动态取色与深浅主题。
- JSON / Markdown / TXT 导出与系统分享。

无需账户，不上传扫描结果，不解密 HTTPS。静态证据与实际连接分别记录。Root 管理器与真实 Shizuku/OEM 行为仍需对应设备授权验证，详见[验证记录](https://github.com/vexpaer/sososafe/blob/v0.1.0/docs/VALIDATION.md)。

发布包使用独立的稳定签名，不能覆盖安装调试签名的 CI 包；如已装调试版，请先导出报告。
