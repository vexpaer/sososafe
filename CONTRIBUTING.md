# Contributing

Clone recursively to obtain pinned native dependencies. Submit a PR; Android CI installs build tools on the runner. No local Android toolchain is required.

Keep UI separate from platform access, retain unknown states, and attach a source and evidence level to every finding. Changes to privileged commands must extend the allowlist and injection/rollback tests. Changes to forwarding must retain IPv4/IPv6 TCP/UDP tests and the emulator TUN test. Never disable Lint or replace observed results with fixture values in production.

Domain signatures belong in the offline TSV database, ordered by host specificity at runtime. Explain category evidence in the PR. Adding a vendor-wide domain must not label its functional services as advertising without evidence. Retain dependency copyright and license notices.

Do not commit signing keys, reports, device identifiers or real packet captures. Use synthetic protocol fixtures for tests. Security issues: see SECURITY.md.
