# sososafe native interface

Mode: Operate. Product truth and the brief pin Material Design 3 as the visual authority. No concept interview is needed because the user explicitly requests autonomous implementation.

Grounded options considered: device maintenance dashboard, privacy permission manager, inspection ledger, packet trace console, incident review, app catalog, Android settings. The inspection ledger is the selected direction: clear labels, evidence grouped by source, a stable path from application to finding to reversible action. Material components own structure; dynamic color owns the default palette. Teal is the static fallback.

Use Material type roles, generous section spacing and compact evidence rows. Tab bar on phones; navigation rail on wide displays. Keep raw evidence selectable. Empty, denied, cancelled and failed states offer the corresponding recovery action. System Back closes detail screens. App icons come from installed packages.

The brief's Material commitment takes priority over decorative challenger worlds. Retained disciplines: consistent columns from departure boards; readable touch targets from consumer surfaces; progressive disclosure from catalogs; consistent labels from identity systems; preserved history from ticket records. No sampled visuals, fabricated counters or animation-only controls.
