# sososafe

Android native, offline privacy auditor for Chinese and English speaking device owners. The user wants all scanning modes, APK inspection, evidence-based reports, reversible actions and local network monitoring in one installable product. No account, telemetry, external VPN or local development tools.

## Stack
Kotlin, Compose, Material 3, Room, DataStore. Android 8+. GitHub Actions owns all Android builds and tests.

## Commitments
Use native Material navigation, dynamic color, light/dark/system themes. Display measured facts and access limitations; never invent results or call static correlations proven leaks. Root authorization and VPN activation require a deliberate device action. The supplied brief authorizes implementation choices without an interview.

## Assumptions
Private GitHub repository `vexpaer/sososafe`. First launch requires a 中文 / English choice, persisted and editable in Settings. Default theme follows the system. The user requests direct publication of signed release v0.1.0 after CI verification. Preserve a stable private signing key outside the repository and put build credentials in GitHub Secrets.
